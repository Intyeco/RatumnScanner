# RatumnScanner Project

RatumnScanner Project is a new generic translation pen hardware project, it use Rockchip RV1106G series SoC.

Ratumn翻译笔项目是一个新的、划时代的开源翻译笔硬件项目。本项目提供了一个基于RV1106G系处理器的硬件设计参考，使用嘉立创EDA设计

If you want to use RentaKernel-RSP from CraftIO China, it must worked with 256MB SPINand storage chip.

如果你需要使用来自创瑞通中国的RentaKernel RSP开源系统，则必须使用256MB的Flash存储单元（SPINand颗粒）

This project provide a new design of DictPen, and help developers to quickly test their own system on it.

本项目提供了一个快速的翻译笔硬件设计，帮助开发工程师更快地去测试他们的系统以及硬件，节约开发成本
